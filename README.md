# CarePoint Hospital Website — Student Project

A responsive, single-page hospital and healthcare website built with HTML, CSS and vanilla JavaScript.

## Run in VS Code
1. Extract the ZIP file.
2. Open the `medicare-hospital-website` folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Project structure
- `index.html` — page content and sections
- `css/style.css` — responsive styling and layout
- `js/script.js` — mobile navigation, date validation and demo appointment form

## Features
- Responsive layout for desktop, tablet and mobile
- Hospital introduction and key statistics
- Medical departments and doctor profile cards
- Medical services and health information
- Appointment request form with basic validation
- Emergency call link (`108`)
- Mobile navigation menu

## Before submitting
- Replace the fictional hospital name, contact information and sample doctor profiles if your college requires your own details.
- Images are loaded from Unsplash, and Google Fonts are loaded online; internet access is needed for those assets.
- The appointment form is a front-end demonstration only. It does not send, store or book appointments.
- The emergency number is shown as a general India emergency contact. Do not present this student demo as a real hospital service.
